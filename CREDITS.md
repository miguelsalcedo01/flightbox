# Credits

Flightbox builds on open-source software, substantially extended and tailored
for spend governance and audit use cases.

- The workflow-orchestration core derives from an MIT-licensed open-source
  project; the original copyright notice is preserved in [`LICENSE`](LICENSE)
  as that license requires. Flightbox is an independent product — it is not
  affiliated with or endorsed by the original author.
- Additions original to Flightbox include: the budget-gate and approach-warning
  system, approval phases, pre-run cost estimates and monthly budget
  projection, the spend roll-up dashboard, the plain-language session replay,
  the Claude Code backend, and the one-line installers.

Third-party runtime dependencies are listed in the visualizer's
`package.json` and each ADW script's inline metadata.
